Scope of this evidence

How to re-run

python tools/ui_preview.py, then python tools/a11y_check.py (page checks, contrast, focus-not-obscured). The script exits with an error if any check fails. Target size, reflow and zoom were measured in Chromium (Playwright) at 1280px, 640px and 320px widths.
